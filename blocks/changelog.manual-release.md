## Changelog

- A normal pull request does NOT edit `CHANGELOG.md`. The file is
  written at release time, by whoever coordinates the release.
- A pull request with a change a user of the release could observe
  describes it in a `## Changelog` section of its body. At release time
  the coordinator moves those lines into `CHANGELOG.md`.
- Which pull requests must carry that section, and the format of its
  lines, are set in the repository-specific sections below.
